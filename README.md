# Фильтр результатов тестирования

**Сравнивайте результаты тестов и находите варианты, которые показывают себя лучше.**

[Посмотреть демо](https://tests-filter.vercel.app/)

Приложение помогает исследовать выборку результатов тестирования версий программного обеспечения: отфильтровать записи по значению и варианту теста, увидеть наиболее успешные значения и подробнее изучить отдельные результаты.

## Возможности

- **Фильтрация выборки** по значению показателя и варианту теста A или B.
- **Быстрый доступ к наиболее успешным значениям** с указанием числа успешных исходов и размера выборки.
- **Настройка топа значений**: минимальный размер выборки, количество значений и нижний порог. Порог также ограничивает список значений фильтра; уже выбранное значение сохраняется.
- **Карточки результатов** с основными и дополнительными значениями, отмеченным исходом и показателями по периодам.
- **График по периодам** в карточке, когда для обоих вариантов достаточно данных.
- **Ссылки на отфильтрованную выборку**: выбранные фильтры сохраняются в адресе страницы.

Статистика помогает изучать выборку, но сама по себе не доказывает статистическую значимость различий и не гарантирует, что один вариант лучше во всех условиях.

Настройки топа применяются сразу и действуют до обновления страницы. Они не меняют исходные данные или уже выбранный фильтр записей: для изменения показанных карточек выберите другое значение.

## Начало работы

Для запуска нужны Node.js, npm и доступ к MongoDB с данными приложения.

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Создайте в корне проекта файл `.env.local` и укажите строку подключения:

   ```env
   MONGODB_URI=<строка подключения к MongoDB>
   ```

   Приложение использует базу `testdb` и коллекцию `nba`. В ней должны находиться записи в формате, ожидаемом приложением.

3. Запустите сервер разработки:

   ```bash
   npm run dev
   ```

4. Откройте [localhost:3000](http://localhost:3000/), выберите значение и, при необходимости, вариант теста.
